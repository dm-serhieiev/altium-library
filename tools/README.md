# Інструменти бібліотеки Altium

`inventree-sync.exe` оновлює базу компонентів із InvenTree. Незалежний `setup-odbc.exe` налаштовує локальне підключення Altium до неї. Готові програми для Windows не потребують установленого Python або PowerShell; звичайна робота не потребує прав адміністратора. Зберігайте їх у `tools/` разом зі структурою репозиторію.

## Налаштування синхронізації

Поруч із `inventree-sync.exe` потрібен локальний `config.toml`. Якщо його немає, вручну скопіюйте [config.example.toml](config.example.toml) у `tools/config.toml`, задайте адресу сервера без `/api/` і точний шлях кореневої категорії. Не перезаписуйте наявний файл. Програма не створює конфігурацію і не шукає її в інших папках.

Усі відносні шляхи рахуються від `tools/config.toml`: `[sync]` задає вихідну базу та DbLib, `[libraries]` — папки символів і footprints. Типовий вихід — `../database/components.sqlite`; синхронізатор підтримує також `.sqlite3`. **Setup завжди використовує `database/components.sqlite` і не читає TOML**: залишайте типовий шлях для спільної роботи цих двох програм.

За замовчуванням кожна команда синхронізації один раз запитує Username та прихований Password. Пароль не зберігається; секрети в конфігурацію не додавайте. HTTP та HTTPS підтримуються; HTTP не шифрує Basic Auth, а HTTPS перевіряє сертифікат. Локальний `config.toml` не додавайте в Git.

## Запуск синхронізації

Закрийте Altium та інші споживачі бази. Двічі клацніть `tools/inventree-sync.exe`: виконається sync. У власному вікні Провідника програма чекатиме Enter після завершення, допомоги або помилки. У вже відкритому терміналі та автоматизованому запуску паузи немає.

Або виконайте з кореня репозиторію:

```powershell
.\tools\inventree-sync.exe
.\tools\inventree-sync.exe validate
.\tools\inventree-sync.exe inspect
.\tools\inventree-sync.exe --help
```

`sync` можна вказати явно. `inspect` читає і показує зведення джерела; це не повна перевірка експорту. `validate` перевіряє весь експорт у пам'яті без вихідних файлів. `sync` публікує нову базу після перевірок. Помилка до публікації зберігає попередню базу; повідомлення про помилку прибирання після публікації окремо вказує, що файл уже оновлено.

## Підключення Altium через ODBC

Потрібні Windows x64 і вже встановлений **64-бітний SQLite3 ODBC Driver** (`sqlite3odbc.dll`). За відсутності встановіть відповідний пакет `sqliteodbc_w64.exe` окремо з [сайту SQLite ODBC](https://www.ch-werner.de/sqliteodbc/). Setup показує SQLite-драйвери, але не завантажує і не встановлює їх.

Закрийте споживачів бази й двічі клацніть `tools/setup-odbc.exe`, або виконайте:

```powershell
.\tools\setup-odbc.exe
.\tools\setup-odbc.exe --check-only
.\tools\setup-odbc.exe --help
```

Setup створює User DSN **AltiumComponents** для поточного користувача, перевіряє наявну базу та підключення. `--check-only` нічого не змінює; відсутній DSN або неправильний шлях означає помилку. Необов'язковий `--driver-name 'точна назва'` вибирає лише сумісний установлений alias драйвера. Шляхи з пробілами/Unicode підтримуються, із `;` — ні.

Після переміщення репозиторію запустіть setup знову: для сумісного DSN зміниться лише Database. Правильний еквівалентний шлях не переписується. Один DSN відповідає одному активному клону. Програма не потребує доступу до InvenTree, не створює/ремонтує SQLite та не редагує бібліотеки Altium.

В **ODBC Data Sources (64-bit) → User DSN** перевірте AltiumComponents, SQLite3 ODBC Driver і абсолютний шлях. Відображення User DSN також у 32-бітному адміністраторі саме по собі не підтверджує бітність драйвера.

Після повідомлення `Altium database connection is ready.` відкрийте [Components.DbLib](../database/Components.DbLib) та виконайте **Connect**. Connection string уже використовує DSN=AltiumComponents. Вручну перевірте таблиці, IPN як ключ, [mappings](inventree-sync/README.md#altium-integration), символ і передачу footprint на PCB. Звичайний параметр `InvenTree PK` мапується без дужок, Comment символу — `=Value`. Зміни категорій можуть потребувати нових mappings.

## Робота без сервера

Перевірений [components.sqlite](../database/components.sqlite) зберігається в репозиторії для автономної роботи Altium через ODBC. Він може відставати від InvenTree. Невдала спроба доступу до API залишає цей файл незмінним і повертає код помилки; повторіть sync після відновлення доступу.

Виправляйте компоненти в InvenTree: ручні зміни SQLite наступна синхронізація замінить. Оновлений знімок зберігайте в Git лише після перевірки цілісності, вмісту, роботи Altium та відсутності залежності від журналів. Програми не створюють комітів і не виконують push.

## Якщо виникла помилка

| Повідомлення / ситуація | Дія |
|---|---|
| Configuration file not found | Створіть конфігурацію саме поруч із inventree-sync.exe за прикладом |
| HTTP 401/403 або мережа | Перевірте доступність сервера, адресу, облікові дані та права; для прихованого вводу потрібна інтерактивна консоль |
| Missing library file | Перевірте `[libraries]` відносно TOML і явні посилання Altium Symbol/Footprint в InvenTree |
| Немає x64 драйвера | Установіть його окремо; 32-бітний не підходить |
| Конфлікт User/System DSN, драйвера або Rollback incomplete | Перевірте DSN вручну; не редагуйте його паралельно із setup. Автоматичного Force немає |
| Відсутня/пошкоджена база | Відновіть перевірений знімок або виконайте успішний sync; setup її не ремонтує |
| Блокування, -wal/-shm/-journal | Закрийте споживачів нормально та дайте їм завершити транзакції/відновлення. Не видаляйте журнали для обходу перевірок |
| Покинутий .sync.lock | Дотримуйтеся [процедури відновлення](inventree-sync/README.md#recovery-procedure); спершу підтвердьте зупинку власника та всіх sync до цієї бази |

Коди inventree-sync: `0` успіх, `1` внутрішня помилка, `2` конфігурація/дані/ввід, `3` API/авторизація, `4` база/файли/публікація. Коди setup-odbc: `0` перевірено, `1` помилка налаштування/виконання, `2` неправильні аргументи.

Технічні інструкції та тести: [inventree-sync](inventree-sync/README.md), [setup-odbc](setup-odbc/README.md). Правила бібліотеки: [категорії](../docs/inventree-category-structure.md), [IPN](../docs/ipn-naming-convention.md), [моделі Altium](../docs/library-convention.md).
